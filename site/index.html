jz

    

    

      
      
      
      
      
    

    
Bare jz runs the default recipe, like just: here it calls justz help. Bare jzh shows the help and runs nothing.

    
With a command registry, a bare name such as clean finds its group, tool; without one, type jz tool clean.

  


  

    
One source of truth

    
just --list is fine for a dozen recipes. Past that, two things get hard.

    

      

        
Discovery

        
A new teammate, or an AI agent, cannot tell what the project can do, which flags a command takes, or which commands are safe to run.

      

      

        
Drift

        
The help text, the docs and the recipes slowly disagree, and nobody notices until someone is misled.

      

    

    
The help, the completion and the checks all read the same data, so they cannot disagree.

To document a project's commands, ask an agent that has the justfile-authoring skill: it reads the recipes and writes the documentation. Without an agent, justz init scaffolds a new project, and you add the commands by hand. Where the documentation lives, and what that needs: Variants.

  


  

    
How you type it

    
You keep typing just. The short forms are there when you want them.

    

      
just
Your justfile's own recipes. justz init --variant rich writes just, just help and just check so that they call justz.

      
jz jzh
Shortcuts for the project around the current directory, from any subdirectory. justz setup adds them; Homebrew installs them.

      
tz tzh
A shim pinned to one project, under a name you choose, from any directory. Added with justz shim add.

      
justz
The CLI itself. justz help and justz check work in any project with a justfile, with no setup.

    

  


  

    
What you get

    

      justz help
Grouped commands with flags and examples. Drill into one with justz help <group> <command>.

      justz check
Fail CI when the docs and the recipes disagree. Pre-commit and Actions snippets included.

      justz lint
Advice on recipe antipatterns: long bodies, secrets on the command line.

      justz init
Scaffold a self-documenting project that is green from the first run.

      justz completions
Tab completion for zsh and bash, from the same data as the help.

      justz setup
Check the machine and add the jz and jzh shortcuts. It never takes a name that another command on your PATH has.

      justz shim add
Run a project's commands from any directory, safely, under a short name.

      justz fmt justz schema
Keep the command registry in one stable order, with editor completion and type checks for commands.json.

Design principles

    
    
      
  • One binary. No jq, awk, Python or Node.
    • 
      
  • Reads just the supported way through its JSON dump.
    • 
      
  • Stays out of your secrets. Never reads, stores or injects credentials.
    • 
      
  • Safe output. Escape sequences in descriptions never reach your terminal.
    • 
      
  • Verified releases. SHA256 checksums and provenance attestations.
