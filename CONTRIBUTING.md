# Contributing

`justz` is maintained by one person in their own time. It is not open for code contributions yet.

## What helps

| You have | Do this |
|---|---|
| A bug | Open an [issue](https://github.com/igorlino/justz/issues) with the bug report form. Say what you ran, what you saw and what you expected, with the output of `justz --version` and `just --version`. |
| An idea | Open an [issue](https://github.com/igorlino/justz/issues) with the feature idea form. Say what you were trying to do. |
| A security problem | Do not open an issue. Follow [SECURITY.md](SECURITY.md). |
| A question about using `justz` | Read [FAQ and troubleshooting](docs/faq.md). If the answer is not there, open an issue with the bug report form: a question the docs do not answer is a gap in them. |

A pull request that nobody asked for is likely to be closed without a review. This is about time, not about your change: open an issue first.
